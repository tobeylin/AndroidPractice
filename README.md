# PlaygroundWeather

An Android weather app built with Jetpack Compose and Kotlin.

## Tech Stack

* Kotlin
* Jetpack Compose (Material 3)
* Hilt (Dependency Injection)
* Retrofit + OkHttp (Networking)
* Room (Local Storage)
* Multi-module architecture

## Architecture

The project follows the official Android architecture guidance using a three-layer Unidirectional Data Flow (UDF) pattern: UI → Domain → Data.

```
:app                  — Entry point, navigation, DI setup
:feature:weather      — Weather screen UI + ViewModel
:core:data            — Repositories, data sources
:core:model           — Shared data model classes
:core:network         — Remote data sources (Retrofit + OkHttp)
:core:database        — Local data sources (Room)
```

## Prerequisites

* Android Studio (latest stable)
* JDK 17 or higher
* An OpenWeatherMap API key

## Getting Started

1. Clone the repository: `git clone <repo-url>`
2. Open the project in Android Studio
3. Add your API key to `local.properties` (auto-generated by Android Studio in the project root; create it manually if building from the command line):
   ```
   WEATHER_API_KEY=your_api_key_here
   ```
   **Important**: Do not wrap the value in quotes. The app compiles without the key, but API calls will fail at runtime.
4. Build and run the app from Android Studio, or use the commands below

## Build Commands

```bash
./gradlew assembleDebug          # Build debug APK
./gradlew test                   # Run unit tests
./gradlew connectedAndroidTest   # Run instrumented tests (requires device/emulator)
./gradlew lint                   # Run Android lint
./gradlew clean                  # Clean build outputs
```

On Windows, use `gradlew.bat` instead of `./gradlew`.
